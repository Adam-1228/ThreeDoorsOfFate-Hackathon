# Game sound effects

The UI, card, world, and reward WAV files in this directory are original procedural renders.
They are generated by `tools/generate_game_sfx.ps1` with FFmpeg and contain no third-party samples.

- Format: mono, 48 kHz, 16-bit PCM source WAV
- Runtime import: Decompress On Load, ADPCM, preloaded
- Peak ceiling: -1.7 dBFS

The existing clips under `Impact/` retain their separate provenance record in
`Impact/SOURCES.md`.
