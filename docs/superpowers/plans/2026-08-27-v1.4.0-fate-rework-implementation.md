# Three Doors of Fate v1.4.0 Fate Rework Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the `1.4.0` Fate Rework with deterministic 24-card starts, nine contracts, explicit card confirmation, universal checkpoints, varied events and enemies, endless mutations, and local run history while preserving all `1.3.0` progression.

**Architecture:** Add small deterministic rule and catalog classes under `Assets/Scripts/Game/V140`, then connect them through focused controller partials instead of expanding the 12,129-line controller. JSON resources define contracts, events, enemy behavior, and endless mutations; controller partials own Unity UI and migration bridges. Existing IDs, frames, achievements, localization, and Apple services remain authoritative.

**Tech Stack:** Unity 6000.4.11f1, C# and Unity UI, `JsonUtility`, `PlayerPrefs`, NUnit EditMode/PlayMode tests, Python `unittest`, Git LFS.

**Spec:** `docs/superpowers/specs/2026-08-27-v1.4.0-fate-rework-design.md`

## Global Constraints

- Target marketing version is `1.4.0`; reserve iOS build `14000` for the first release candidate.
- Do not submit `1.4.0` until `1.3.0` is approved, has spent meaningful time live, and the user separately approves submission.
- Preserve all existing PlayerPrefs keys, iCloud progress, 20 Game Center achievements, permanent IDs, and the 1,000-point total.
- Do not add Game Center achievements, forced ads, banner ads, IAP, PvP, new currencies, or combat sound effects.
- Reuse existing UI frames and art unless the user separately approves new generated assets.
- User temporarily authorizes Unity for this `1.4.0` task, but memory must remain at least 25%, Unity/Xcode work must be serialized, and iOS export requires at least 12 GiB free.
- Every rule change starts with a failing test, demonstrates the intended failure, implements the smallest coherent behavior, and reruns the affected suite.
- New Korean and English player-facing strings must use localization keys; do not add controller-only Korean copy.
- Every new file under `Assets/` must include and commit its matching Unity `.meta` file, including new folders and JSON resources.

public uint NextUInt()
{
    uint value = state;
    value ^= value << 13;
    value ^= value >> 17;
    value ^= value << 5;
    state = value == 0 ? 0x6D2B79F5u : value;

}
