# App Review 메모

Three Doors of Fate는 싱글 플레이 카드 RPG이며 인앱 구매와 구독이 없습니다.

## 이번 제출

- 심사 대상 빌드: `1.0.3 (7)`
- 한국어와 영어 언어 선택을 추가했습니다. 메인 화면이나 플레이 중 `설정 / Settings`에서 언제든 언어를 바꿀 수 있으며, 전환해도 현재 런과 저장 데이터는 초기화되지 않습니다.
- 메인 메뉴, 설정, 직업과 난이도 선택, 세 문, 전투 HUD와 로그, 보상·상점·이벤트, 업적, 결말과 플레이 방법을 한국어와 영어로 제공합니다.
- 영어 모드에서는 72장의 카드 이름·효과·전체 카드 이미지도 영어로 표시됩니다. 한국어 모드의 기존 카드 데이터와 이미지는 그대로 유지됩니다.
- Game Center 접근점과 우측 상단 설정 버튼이 겹치지 않도록 표시 위치와 노출 화면을 조정했습니다. Settings와 How to Play에서는 Game Center 접근점을 숨깁니다.
- 보상형 광고만 사용하는 기존 정책은 동일합니다. 릴리스 검증은 프로덕션 `GADApplicationIdentifier`, `GADUUnityVersion`, Google Mobile Ads SKAdNetwork 항목, 코드 서명과 개인정보 매니페스트가 누락되거나 소스 설정과 다르면 업로드 전에 실패합니다.
- 최종 아카이브에는 `NSUserTrackingUsageDescription`이 없어야 하며 `ITSAppUsesNonExemptEncryption`은 `false`입니다.

## 언어 확인 경로

1. 앱을 실행하고 메인 화면 오른쪽 아래의 톱니바퀴 `설정 / Settings`을 선택합니다.
2. `한국어` 또는 `English`를 선택합니다.
3. `게임 시작 / Start Game`을 선택해 난이도와 캐릭터를 고른 뒤 문 선택과 전투로 진입합니다.
4. 영어 모드에서는 카드 프리뷰의 카드명·규칙·이미지와 전투 로그의 카드명까지 영어로 표시됩니다.
5. 플레이 중 오른쪽 위 `Settings`에서 다시 한국어로 전환할 수 있습니다.

## 로그인과 저장

- 앱 시작 시 Apple Game Center 시스템 인증 화면이 표시될 수 있습니다.
- Game Center 로그인은 클라우드 저장, 업적과 리더보드에 사용됩니다.
- 앱 사용 자체에는 로그인이 필요하지 않으므로 App Review의 `Sign-in required`는 `No`입니다.
- 로그인을 취소하거나 오프라인이어도 로컬 저장과 전체 싱글 플레이를 계속 사용할 수 있습니다.
- 별도 개발자 계정, 사용자 이름 또는 비밀번호가 없으므로 데모 계정도 없습니다.

## 보상형 광고 확인 경로

1. 앱을 실행하고 `게임 시작 / Start Game`을 선택합니다.
2. 난이도 하나를 선택한 뒤 도박사, 예언가 또는 추방자를 선택합니다.
3. 캐릭터 확정 화면 아래의 선택형 보상 광고 버튼을 선택합니다.
4. 광고를 취소하거나 광고·보상이 실패하면 유물과 일일 횟수가 차감되지 않습니다.
5. 보상을 끝까지 완료하면 현재 난이도에서 허용되는 미발견 유물 하나만 지급되고 해당 캐릭터의 오늘 성공 횟수가 1회 증가합니다.

한 캐릭터당 로컬 달력 기준 하루 최대 3회의 성공 보상만 허용됩니다. Easy는 Easy 유물, Normal은 Easy·Normal 유물, Hard는 전체 난이도 유물 중 미발견 항목을 사용합니다. 받을 수 있는 미발견 유물이 없으면 광고 진입은 표시되지 않습니다. 자동 광고, 전면 광고와 배너 광고는 없습니다.

## 개인정보 선택

이 앱은 맞춤형 광고나 Apple이 정의하는 교차 앱 추적을 하지 않습니다. Google Mobile Ads SDK 초기화 전에 퍼블리셔 1자 식별자와 개인 맞춤 광고 처리를 비활성화하며 ATT 권한을 요청하지 않습니다. 게임의 설정 메뉴에서 적용 지역에 필요한 Google UMP 개인정보 선택 화면을 다시 열 수 있습니다. 개인정보 선택과 광고 사용 여부는 게임과 로컬 저장을 차단하지 않습니다.
