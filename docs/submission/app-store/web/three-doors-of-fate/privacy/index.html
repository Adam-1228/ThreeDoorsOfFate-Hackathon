개인정보처리방침

Three Doors of Fate는 별도의 개발자 계정 서버를 운영하지 않습니다. 게임 진행은 기본적으로 기기에 로컬 저장되며, 사용자가 Game Center와 광고 기능을 사용할 때 Apple 및 Google 서비스가 아래 정보를 처리할 수 있습니다.

1. 기기 안에서 처리되는 게임 정보

선택 캐릭터, 난이도, 해금 상태, 유물, 설정, 점수와 광고 보상 사용 횟수 같은 게임 진행 정보는 로컬 저장에 사용됩니다. 개발자가 운영하는 서버로 이 로컬 진행 정보를 직접 전송하지 않습니다. 앱을 삭제하면 클라우드에 동기화되지 않은 로컬 진행은 사라질 수 있습니다.

2. Game Center 및 iCloud

사용자가 Game Center에 로그인하면 Apple의 GameKit과 iCloud가 플레이어 인증, 클라우드 저장, 점수, 업적과 충돌 해결을 위해 플레이어 식별 정보와 게임플레이 콘텐츠를 처리할 수 있습니다. 로그인하지 않거나 로그인을 취소하면 클라우드 동기화·업적·리더보드는 사용할 수 없지만 로컬 저장과 오프라인 플레이는 계속됩니다. Apple 서비스의 데이터 처리는 Apple의 개인정보 보호정책과 사용자 계정 설정을 따릅니다.

3. Google Mobile Ads

앱은 사용자가 직접 선택하는 유물 획득 보상형 광고에 Google Mobile Ads SDK와 동의 관리 기능을 사용합니다. SDK는 광고 제공, 빈도 제한, 분석, 성능 개선, 사기 방지와 보안을 위해 다음 정보를 수집하거나 처리할 수 있습니다.

  • IP 주소에서 추정되는 대략적 위치
  • 기기 식별자 또는 광고 식별자
  • 표시되거나 상호작용한 광고 데이터
  • 앱 실행, 탭, 동영상 시청 같은 제품 상호작용
  • 충돌 로그, 진단 정보와 앱 실행 시간·중단·에너지 사용 같은 성능 데이터

실제 처리 범위는 iOS 권한, 동의 상태, 광고 제공 모드와 Google SDK 설정에 따라 달라질 수 있습니다. 자세한 내용은 Google 개인정보처리방침과 Google Mobile Ads iOS 데이터 공개 안내에서 확인할 수 있습니다.

4. 추적 및 선택권

이 앱은 맞춤형 광고 또는 Apple이 정의하는 교차 앱 추적을 하지 않습니다. Google Mobile Ads의 퍼블리셔 1자 식별자와 개인 맞춤 광고 처리를 비활성화하며 앱 추적 투명성 권한을 요청하지 않습니다. 적용 지역의 광고 개인정보 선택은 게임 설정의 개인정보 메뉴에서 다시 확인할 수 있고, 해당 선택과 광고 사용 여부는 게임 진행과 로컬 저장을 차단하지 않습니다. iOS의 개인정보 보호 및 Game Center/iCloud 설정도 사용할 수 있습니다.

5. 보관, 삭제 및 문의

로컬 정보는 사용자의 기기와 앱 저장 공간에 보관됩니다. 앱 데이터 삭제 또는 앱 제거로 로컬 정보를 지울 수 있습니다. Game Center·iCloud와 Google이 보관하는 정보의 관리·삭제는 각 서비스의 계정 및 개인정보 도구를 사용해야 합니다. 추가 문의는 개인정보 문의 이메일로 보내 주세요.

6. 방침 변경

기능이나 제3자 SDK의 데이터 처리가 달라지면 이 페이지와 App Store의 개인정보 공개를 함께 갱신합니다.

English summary

Progress is stored locally by default. Game Center sign-in enables Apple GameKit/iCloud save synchronization. Optional rewarded ads use Google Mobile Ads, which may process device, advertising, interaction, approximate-location, crash, diagnostic, and performance data as described above.
