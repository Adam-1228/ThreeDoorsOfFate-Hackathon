지원 및 문제 해결

문의할 때 기기 모델, iOS 버전, 문제가 발생한 화면과 재현 순서를 알려 주세요. Apple ID, Game Center 계정명, 광고 식별자 같은 개인정보는 보내지 마세요.

저장과 Game Center

  • 로컬 저장은 Game Center 로그인 여부와 관계없이 기기에 유지됩니다.
  • 클라우드 저장 동기화, 업적과 리더보드는 Game Center 로그인이 필요합니다.
  • 로그인을 취소했거나 오프라인이면 로컬 플레이를 계속한 뒤, 나중에 로그인해 동기화를 다시 시도할 수 있습니다.
  • 앱 삭제 전에는 클라우드 동기화 상태를 확인하세요. 동기화되지 않은 로컬 데이터는 앱 삭제 시 사라질 수 있습니다.

보상형 광고

  • 미발견 유물을 받으려는 사용자가 직접 광고 버튼을 선택할 때만 표시됩니다.
  • 광고 취소·재생 실패·보상 처리 실패 시 유물과 사용 횟수를 차감하지 않습니다.
  • 광고 준비 중에는 네트워크를 확인하고 잠시 후 다시 시도해 주세요.
  • 광고 개인정보 선택은 게임 설정의 개인정보 메뉴에서 다시 열 수 있습니다.
