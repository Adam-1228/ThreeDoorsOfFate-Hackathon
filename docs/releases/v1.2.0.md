# Three Doors of Fate v1.2.0

Released: 2026-08-25

## Highlights

- Expanded the in-game achievement collection to 20 achievements and 1,000 total Game Center points.
- Added 12 original 1024×1024 achievement illustrations with matching Korean and English titles, discovery conditions, and earned descriptions.
- Rebuilt Achievements as a 5×2 relic-style discovery gallery: undiscovered entries conceal their identity, while completed entries open one shared detail panel.
- Added a fixed Settings entry to character confirmation and class detail screens.
- Increased the safe padding for the door-selection progress log.
- Cropped shop relic art inside a safe viewport and retained one existing decorative frame overlay.
- Kept action and UI sound effects disabled while preserving the existing scene, combat, and boss background music.
