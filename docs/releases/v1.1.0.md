# Three Doors of Fate v1.1.0

v1.0.0 이후의 PC UI 가독성, 효과음 라우팅, Apple 플랫폼 연동 및 배포 자동화 개선을 반영한 소스 릴리스입니다.

## 주요 변경

- 카드 표시를 소형·표준·상세 모드로 분리해 제목, 비용, 효과 텍스트의 가독성을 개선했습니다.
- 상태 확인, 업적, 유물, 캐릭터 선택과 상단 안내 UI의 프레임·박스·안전 여백을 통일했습니다.
- UI, 카드, 전투, 보상, 상점, 저장 동작별 효과음 라우팅을 추가하고 캐릭터 선택의 불필요한 공용 클릭음을 제거했습니다.
- Game Center, iCloud 진행 동기화, Google Mobile Ads와 개인정보 동의 기반을 추가했습니다.
- iOS Privacy Manifest, entitlements, Xcode 후처리와 Mac/iOS 빌드·전달 도구를 추가했습니다.
- 앱 버전은 `1.1.0`, iOS 기본 빌드 번호는 `2`입니다.

## 카드와 밸런스 확인

- 카드 데이터: 72개 (v1.0.0과 동일)
- 일반 카드 렌더: 48개 (v1.0.0과 동일)
- 하드 카드 렌더: 24개 (v1.0.0과 동일)
- 카드 데이터와 렌더 파일 해시: v1.0.0과 동일
- 확인된 카드 비용·효과·수량 수치 변경 없음
- 금 보상 `+30`은 효과음 경로만 변경했으며 지급량은 동일

## 검증

- Windows 플레이어 빌드 성공
- Unity EditMode 138/138 통과
- Apple 플랫폼 보조 스크립트 7/7 통과
- Mac, Xcode, iOS 실기기 서명·실행은 Windows 환경에서 새로 검증하지 않음
